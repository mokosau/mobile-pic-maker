# 初期ユーザー獲得戦略

MVPリリース後、最初のユーザーベースを構築するための戦略案です。

### 1. プロダクト関連のオンラインコミュニティでの発信

- **対象**:
  - Indie Hackers, Product Hunt, Zenn, Qiita などの、個人開発者やスタートアップ関係者が集まるコミュニティ。
  - X (旧Twitter) の #駆け出しエンジニアと繋がりたい, #個人開発 などのハッシュタグ。

- **内容**:
  - 「こんなツールを作りました！」という形式で、サービスの紹介記事やポストを投稿する。
  - 開発の背景、こだわったポイント（e.g., シンプルさ、カルーセル機能）、技術スタックなどを共有し、開発者コミュニティからのフィードバックを求める。
  - Product Huntでのローンチも行い、初期の注目を集める。

- **KPI**:
  - コミュニティからの流入数
  - Product HuntでのUpvote数
  - SNSでのメンション数

### 2. アプリ開発者向けメディア・ブログへの掲載依頼

- **対象**:
  - アプリ開発者向けのブログ、ニュースサイト、インフルエンサー。

- **内容**:
  - サービスのプレスリリースを作成し、関連メディアに送付する。
  - 「無料で使えるアプリスクショ作成ツール」という切り口で、アプリ開発者の作業効率化に貢献できる点をアピールする。
  - ツールを実際に使ってもらい、レビュー記事を書いてもらうよう依頼する（インフルエンサーにはギフティングなども検討）。

- **KPI**:
  - メディアからの被リンク数
  - 掲載記事経由の新規ユーザー数

### 3. SEO (検索エンジン最適化) によるオーガニック流入の獲得

- **対象**:
  - 「アプリ スクリーンショット 作成」「app store screenshot generator」「App Store 画像 サイズ」などのキーワードで検索しているユーザー。

- **内容**:
  - サービスサイトのタイトルやディスクリプションを最適化する（基本的なSEO対策）。
  - 上記キーワードに関連するブログ記事（例: 「売れるアプリのスクリーンショット作成ガイド」「App Storeの最新画像要件まとめ」）を作成し、ツールへの導線を設置する。
  - 長期的な施策としてコンテンツマーケティングを行い、オーガニック検索からの安定した流入を目指す。

- **KPI**:
  - ターゲットキーワードでの検索順位
  - オーガニック検索からの流入数
  - コンテンツ経由のコンバージョン率

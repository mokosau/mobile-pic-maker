# 技術スタック

本プロジェクトで採用する技術スタックは以下の通りです。

## 技術スタック構成図

```mermaid
graph TD
    subgraph "フロントエンド (クライアントサイド)"
        A[Next.js 14+ (App Router)]
        B[React (Server Components)]
        C[TypeScript]
        D[Tailwind CSS]
        E[html2canvas (画像生成ライブラリ)]
    end

    subgraph "デプロイメント"
        F[Vercel]
    end

    A --> B
    A --> C
    A --> D
    A --> E
    A --> F
```

## 選定理由

| 技術 | 選定理由 |
| :--- | :--- |
| **Next.js 14+ (App Router)** | **制約条件**。最新のReactの機能を活用でき、パフォーマンスと開発者体験に優れているため採用します。App Routerを前提とします。 |
| **TypeScript** | **制約条件**。厳格な型チェックにより、コードの品質と保守性を高めます。strict modeを有効にして開発を進めます。 |
| **Tailwind CSS** | **制約条件**。ユーティリティファーストなCSSフレームワークであり、迅速なUI開発が可能です。 |
| **html2canvas** | ユーザーが編集したHTML要素（デバイスフレーム、テキスト、背景）をクライアントサイドで画像に変換するために採用します。サーバーサイドの処理が不要なため、実装がシンプルで高速に動作します。 |
| **Vercel** | **制約条件**。Next.jsとの親和性が非常に高く、デプロイプロセスが非常にシンプルなため採用します。 |

## 補足: データベースについて

MVPの段階では、ユーザー認証やデータの永続化は不要です。すべての処理はブラウザ上で完結するため、**データベースは導入しません**。
将来的にユーザー機能（作成したデザインの保存など）を実装する際には、SupabaseなどのBaasの導入を検討します。
